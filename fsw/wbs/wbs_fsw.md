# wbs_fsw

work breakdown structure for fsw

## purpose

organize work into manageable tasks

## approach

- top-down decomposition of work
- hierarchical task organization
- define deliverable-oriented work packages

## structure

- level 1: major work areas
- level 2: sub-tasks within each area
- level n: smallest manageable work units

## principles

- mutually exclusive tasks
- collectively exhaustive coverage
- deliverable-oriented decomposition
- appropriate level of detail
