# fbs_fsw

functional breakdown structure for fsw

## purpose

define system functions and capabilities

## approach

- top-down decomposition of functions
- hierarchical functional organization
- capability-oriented breakdown

## structure

- level 1: major functional areas
- level 2: sub-functions and operations
- level n: smallest functional units

## principles

- function-oriented decomposition
- user and system perspectives
- clear functional boundaries
- traceable to requirements
