# fsw

- fsw is flight software.
- fsw means satellite flight software here.
- fsw is divided by breakdown structure.

## breakdown structure

- fbs: function breakdown structure.
- pbs: product breakdown structure.
- wbs: work breakdown structure.

## breakdown dependency

- fbs has no pbs or wbs terms.
- pbs has fbs terms. no wbs terms.
- wbs has pbs terms.

## breakdown flow

- fbs provides module. fbs prepares variants.
- pbs selects fbs variant. pbs prepares variants.
- wbs selects pbs or fbs variant.

## breakdown independence

- pbs can exist without fbs.
- wbs can exist without pbs and fbs.
- wbs can use external pbs.
