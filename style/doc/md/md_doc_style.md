# md doc style

## priority

1. one idea per line.
2. use simple word and sentence.
3. use lowercase heading.
4. use ordered list for priority.
5. use unordered list for others.
6. use `-` for unordered list.

## when to use heading

- topic is independent.
- topic needs explanation.

## when to use unordered list

- items are in same topic.
- items need no explanation.

## link

- files in same base directory form a closed system.
- use link to reference, not copy.
- define once, link from others.
